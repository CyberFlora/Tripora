# Tripora

Tripora is an AI-powered personalized travel planning platform.

## Project Structure

- `frontend/` - React frontend and user interface
- `Backend/` - Node.js + Express backend
- `AI/` - Gemini-powered itinerary generation
- `database/` - Supabase/database related files

## Services

- OpenStreetMap - location geocoding
- OSRM - route, distance and travel time
- Open-Meteo - weather information
- Gemini - personalized itinerary generation
- Supabase - database and authentication

## Team Workflow

All team members work on separate feature branches.
Changes are merged into `main` through pull requests.
